# 宝可梦梦世界 · 从梦之树到 NDS 卡带

[English](../README.md) · [日本語](README.ja.md) · 简体中文

这是第五世代梦世界的社区复原版。你可以在电脑上探索梦之岛、和宝可梦交朋友、到梦之树许愿，再用自己的卡带到连入之森亲手捕获它。本仓库提供搭建私服所需的源码改动和安装工具。

## 不用掌机，试玩全部 12 个小游戏

在首页或梦世界游戏画面上方点 **小游戏试玩**，选游戏就能玩。结束后可点 **再玩一次**，也可以返回选别的。试玩自带宝可梦和树果，不用登录、让宝可梦睡觉或连接 NDS。正式宝箱、梦之树许愿和卡带回传记录都独立保存。菜单可切换语言，部分原版小游戏的图片内仍有日文。[在开服电脑上打开中文试玩](http://127.0.0.1:8088/practice/)

手机和开服电脑连同一个 Wi-Fi，在网页的手机访问入口查看手机应打开的网址，进入首页后点 **小游戏试玩**。想获取可带回卡带的伙伴和道具时，回到正式梦世界游玩。

## 和配对好友一起玩

在 **梦好友 → 好友资料** 里，可以帮干燥的田块浇水，也可以用自己宝箱里的道具交换对方架上的道具。双方更新并成功同步一次后，朋友关机也能提交。你付出的道具会先留出，等两边再次连接时结算。如果对方已经换走目标道具，你会收到退款。进好友资料可以看每次操作的结果。

用自己的账号去另一台服务器玩时，活动配信页面也会带上领取记录和待领队列。玩完先同步回自己的服务器，再用自己的卡带接收。扫描实体卡带的礼物卡册请在自己的服务器操作。

## 日版 PWT 下载大会

打开 **活动配信 → 日版配信图鉴 → Pokémon World Tournament**。档案有 10 份文件，对应 9 个赛事编号，少年组含早期版和修正版。可以直接下载赛事，也可选择日版 **《黑2／白2》** 的 512 KiB 原始 `.sav` 备份。浏览器会检查三个赛事位，标出已安装的大会。点 **加入存档副本** 会使用一个空位并下载新副本，连续添加会保留前面的选择。保留原始备份。在游戏的 PWT 会场选择联网下载大会，私服提供 9 项大会，少年组使用修正版。已验证目录和数据校验值，实体《黑2／白2》从会场接收大会仍待实测。[在开服电脑上打开大会](http://127.0.0.1:8088/campaign/japan/tournaments/) · [赛事档案](https://projectpokemon.org/home/files/category/51-pok%C3%A9mon-world-tournaments/)

## 自己一个人玩

**让掌机和运行梦世界的电脑连到同一个家用网络就行。** 连同一个 Wi-Fi 或热点都可以，只要两台设备能互相访问。自己玩无需安装 Tailscale，也无需邀请别人。

1. **电脑开服。** 第一次先按下方的[Windows 安装步骤](#在-windows-上启动私服)装好。以后双击 `runtime` 文件夹里的 `Start-DreamWorld-LAN.cmd`，游玩期间保持窗口打开。
2. **在梦世界网页查 DNS。** 在这台电脑上，点梦世界首页或游戏画面上方的 **「查看我的掌机 DNS」**。页面会显示「主要 DNS」。如果没有显示地址，确认电脑已用局域网模式开服、掌机和电脑已连到同一网络，再点「重新检查」。[直接打开本机中文版 DNS 页面](http://127.0.0.1:8088/player-guide/#dns)
3. **把网页显示的数字填进掌机。** 在网页的 **「在掌机哪里填 DNS」** 选自己的机型，照着步骤打开游戏使用的 Wi-Fi 连接，关闭「自动获取 DNS」，把刚才的数字填进「主要 DNS」，保存并测试连接。下次地址没变就不用重填。

**用手机或平板玩时，**先在电脑上以局域网模式开服，让手机连上同一个 Wi-Fi。在电脑的梦世界首页或游戏画面上方点 **「手机访问网址」**，把显示的完整网址（含端口）输入手机浏览器，用绑定这张卡带的账号登录。宝可梦入睡同步完成后，掌机可以断网，到唤醒时再连回来。在自动局域网模式下，电脑换了 Wi-Fi，等新网络连好后刷新这个页面，就能查到新网址。手机页面已在模拟移动浏览器中验证。[在开服电脑上查看手机访问网址](http://127.0.0.1:8088/player-guide/phone/)

### 在开服电脑上用 melonDS 1.1 玩

1. 启动私服，在这台电脑上打开 **查看我的掌机 DNS**，在设备选项里选 **本机 melonDS 模拟器**。[打开模拟器 DNS 页面](http://127.0.0.1:8088/player-guide/#melonDS)
2. melonDS 使用间接联网模式。在游戏标题菜单打开 **Nintendo Wi-Fi 连接设置**，选连着 **melonAP** 的那一栏，把「自动取得 DNS」改成「否」，把网页显示的数字填入「主要 DNS」，保存并测试连接。私服仅在本机运行时，显示的是 `10.64.0.1`。[melonDS 1.1 的网络设置](https://github.com/melonDS-emu/melonDS/blob/1.1/src/net/Net_Slirp.cpp#L39-L42)
3. 从游戏内的存档继续，点下屏 **C-Gear → Wi-Fi → 游戏同步**，让一只宝可梦入睡。网站如果已认出同步 ID，但提示在等游戏版本，成功入睡一次后再回网页登记。如果点同步就黑屏，先保留游戏内的 `.sav` 副本。连接测试成功后，若汉化版仍在出现联网提示前黑屏，可以用自己的同版本日版原版游戏配合存档副本对照。

### 解除睡眠限制

**原版实体卡只改 DNS。** 私服允许刚唤醒就再次申请入睡，四个版本的测试存档都通过了连续两次上传。卡带会先比较存档里的入睡日期和掌机日期，通过后才向私服索要可入睡的宝可梦名单。正常唤醒回包没有清除这个日期的选项。想在一天里多次玩网页版，可以让同一只宝可梦保持入睡，需要把收获带回卡带时再准备唤醒。

先在游戏内保存并关闭 melonDS。打开网页的 **解除睡眠限制**，核对掌机日期。点 **选择 melonDS 存档文件夹**，选中自己的 .sav，再点 **备份并更新选中的存档**。也可以选择单个 512 KiB 的 .sav 下载副本，再放回模拟器或写回卡带。网页在本设备处理文件。原版卡带在上传前检查等待，只通过 Wi-Fi 无法改写卡内的计时器。[打开网页版](http://127.0.0.1:8088/player-guide/#tuck-in)

掌机关机时也能在网页查看要填写的 DNS。在「我的主页」中，点「可以开始游戏了！」即可进入梦世界。自家招牌显示当前卡带的训练家名。

在游戏内保存并退出 melonDS。双击私服安装目录 `runtime` 里的 **Start-melonDS.cmd**（解除睡眠限制），依次选自己的 melonDS 1.1、平时玩的汉化游戏、同版本同地区的原版游戏和最新的游戏内 `.sav`。助手会复制一份进度。你和朋友各自设置一次，以后双击新文件夹里的 **DreamWorld.cmd**。

| 助手按钮 | 什么时候点 |
| --- | --- |
| 平时游玩（汉化版） | 日常用中文玩。切换前先在游戏内保存，再退出模拟器。 |
| 申请入睡（原版） | 先清除换机或改时钟产生的等待，并按模拟器日期解除当天再次入睡的限制，再启动原版。下屏点 **Wi-Fi → ゲームシンク（游戏同步）**。はい＝是，いいえ＝否，レポート＝保存。选择要入睡的宝可梦，等同步结束。 |
| 唤醒并领取（原版） | 网页选完伙伴并准备唤醒后，用这个按钮打开游戏，再点一次游戏同步。おこす＝唤醒。 |

三个按钮读写同一份进度。助手改动等待前会保留上次备份。受同一个计时器限制的其他活动也会解锁。助手读取 melonDS 里设置的日期。只有上次入睡日期会阻止今天入睡时，才会调整清醒存档里的这项日期。《黑／白／黑2／白2》两种等待都已通过存档测试，同一天完成第二次入睡仍待游戏内验证。之前设置过助手的玩家，打开新版 Start-melonDS.cmd，点「更新『解除睡眠限制』」，再选原来的游玩文件夹即可。实体 DS 在上传前就会检查本地存档。如果你能导出并恢复自己的卡带存档，可以用助手按掌机显示的日期生成单独的 512 KiB 副本并恢复。继续用同一台掌机和同一套时钟设置。[在开服电脑打开入睡指南](http://127.0.0.1:8088/player-guide/#tuck-in) · [等待字段来源](https://github.com/kwsch/PKHeX/blob/6c9583883c7551ac74a4b74180cead249d4277b8/PKHeX.Core/Saves/Substructures/Gen5/AdventureInfo5.cs#L36) · [任天堂游戏同步说明](https://www.nintendo.co.jp/ds/irbj/qa/index.html) · [游戏如何判断当天能否入睡](https://github.com/fuddlesworth/pokebw2/blob/3afa377e9056f6ba75e572f9296b1637fc694a44/src/ov199/gsync_state.c#L1446-L1473)

### 修复《白》简体中文版 2.1 的游戏同步黑屏

用 Python 3.11 或更新版本打开[本地 ROM 修复工具](../tools/repair-white-sync.py)。依次选择未修改的日版《白》、简体中文版《白》2.1，再为新文件选一个名字。工具会核对两份游戏，在你电脑上生成修复版。

以前设置过的玩家，打开 **解除睡眠限制 → 改用《白》汉化同步修复版**，选择新生成的游戏。首次设置时，平时游玩和联网两项都选修复版。三个入口共用原来的进度。下屏点 **Wi-Fi → 游戏同步 → 是** 保存，进入紫色画面后，再选「是」确认联网。

旧汉化版把属于 `a/0/4/3` 的 47 项画面素材放进了 `a/1/4/3`。游戏同步在这里要读取日版的 28 项素材。修复工具保留日版联机程序，恢复这两组素材的位置，保留中文字幕、字库和 Wi-Fi 设置画面，并将两种文本模式里的「GAME SYNC」都改成「游戏同步」。用同一份存档和同一套输入在 melonDS 1.1 核心测试，日版和汉化修复版都到达联网确认页，旧汉化版在相同步骤双屏变黑。此项测试截至联网确认。


## 领取活动配信

打开 **活动配信 → 当前实机接收队列**。第 1 张是掌机下次新连接时会收到的神秘礼物卡。唤醒列表会分别列出本次送回的伙伴、道具和留到下次的项目。页面打开时每 15 秒刷新一次。[查看当前卡带的接收队列](http://127.0.0.1:8088/campaign/queue/)

在 **活动配信 → 神秘礼物** 点 **一键领取全部未领**，可以把所有页面上已确认未领、无需选版本的礼物排到现有队列后面。按钮显示可新增的张数。如果同一组只能领一个版本，请在列表里单独点你想要的版本。然后用 NDS 逐张收卡。

从自己的梦世界首页点 **活动配信**，登录并切换到要接收礼物的存档。列表按卡带版本和语言筛选。更新服务器后，先用这张卡带完成一次游戏同步，以便网站识别它。[在开服电脑上打开中文配信页](http://127.0.0.1:8088/campaign/)

- **梦世界活动**。在伙伴旁点 **配信到我的存档**。在梦世界结束游玩并选准备唤醒，再用掌机的游戏同步唤醒宝可梦，到连入之森捕捉伙伴。网页在掌机确认接收后标记送达。本服从启用配信时开始记录这类活动。
- **神秘礼物**。点 **配信到我的存档**，再从游戏标题画面打开 **ふしぎなおくりもの → おくりものを うけとる → Wi-Fi**（接收神秘礼物）。收卡后进入游戏，在宝可梦中心找配送员领取并保存。一次收一张；排了多张时，可在网页点 **下次接收这张**。
- **核对领取记录**。下一次游戏同步带回有效卡册后，网页会区分已经收卡、待找配送员和已经领取。也可以选择 **检查存档备份** 读取当前卡带最新的原始 `.sav`（512 KiB）。若多种礼物共用卡号，网页会注明能核实到哪一种。旧存档没有足够信息时显示 **待核对**。

礼物卡来自固定版本的活动档案，首次选择某张卡时服务器只下载该卡的数据。游戏和网页通讯已用临时存档测试。我（goiku）已在自己的日版《黑》实体卡带上收到了 C-Gear 壁纸、梦世界活动配信和神秘礼物。下方的皮宝宝照片记录的是梦之树许愿后的实机捕获。[活动档案](https://github.com/projectpokemon/EventsGallery/tree/f1f3095183ee54dca63216164adb1f278714ec55/Released/Gen%205) · [梦世界活动相遇资料](https://github.com/kwsch/PKHeX/blob/master/PKHeX.Core/Legality/Encounters/Data/Gen5/Encounters5Dream.cs)

网页已显示「等待唤醒」时，仍可追加梦世界活动伙伴或保存 C-Gear 壁纸。掌机开始下载时就会确定本次内容。稍后追加的伙伴和这次装不下的伙伴会留到下次唤醒。神秘礼物可直接从游戏标题画面接收。[在开服电脑上查看领取流程](http://127.0.0.1:8088/player-guide/#distributions)

## 好友离线时去他的小屋

双方各自在自己的私服登录绑定卡带的账号。打开梦世界的 **「查看好友」**，选择一种方式把朋友的小岛保存在自己的电脑上。

- **配对一次，自动更新。** 两边启动同一版私服，让电脑连接同一局域网或同一 Tailscale 私有网络。一人在好友页生成邀请码，私下发给对方，30 分钟内有效。同一 Wi-Fi 选局域网地址的码，异地选 Tailscale 地址的码。另一人在自己的好友页粘贴完整邀请码并配对。两边开服在线时，约每 30 秒检查更新并补送脚印。掌机和对战中继可以保持关闭。如果 Windows 防火墙拦住了连接，请允许从本地局域网或好友 Tailscale 地址连接 TCP 8094。
- **用文件分享。** 主人点 **「导出我的小岛快照」** 并发送文件。访客点 **「导入好友快照」** 选择文件，随后就能进屋。需要自动更新和补送脚印时，再做一次配对。导入旧文件会保留本地缓存的较新版本。

**晚上串门。** 在游戏的梦好友地图里选朋友，或在网页「查看好友」里点「去好友家」，就能到他在原版梦世界中的岛。到达后点「进入房间」（日文「部屋に入る」），可以看到他亲手摆放的家具。页面标着上次更新时间。配对后双方开服时自动更新，同一个入口在朋友关闭电脑、私服和掌机后照样能进。配对后，点小屋上方的 **游戏记录 · 好友互动**，可以给干燥的田块浇水、选择道具交换，或查看请求的结算结果。点 **回到小岛** 就回到刚才的房间。你的脚印会留在自己电脑上，等双方重新连通再送到主人那里。重复送达只显示一次。[原版梦世界的好友拜访说明（日文）](https://github.com/minibug1021/dreamworld-assets/blob/6e0550dab8552cd54bd976d4023f9ec0c43f6d7c/ja.pokemon-gl.com/support/help/world/820/index.html#L180)

**带走自己的新伙伴。** 先在自己服用游戏同步让一只宝可梦入睡。进入好友的小屋，选「访客探险」并出发，从三条路中选出和样本相同的脚印。结交伙伴后，用**自己的一枚树果**在梦之树许愿，点「准备唤醒并结束」。回自己服完成游戏同步唤醒，再去连入之森捕获。探险与奖励记录在访客自己的存档中，好友的宝可梦和道具仍归好友。

快照包含游戏版本、训练家名、徽章数、游玩时长、入睡伙伴、梦之点数、库存、家具、勋章和好友板等游戏同步已经取得的展示资料。没有上传过的盒子、队伍和图鉴无法查看。文件中不含完整卡带存档、游戏同步 ID、密码和登录凭据。收到文件的人都能阅读这些展示资料。

## 在 Windows 上启动私服

请预留至少 **6 GB 磁盘空间**。仅解压原版网页镜像就需要约 3.8 GiB。首次安装会下载本版使用的上游代码和资源，并准备游戏文件。镜像较大，下载和解压可能需要一段时间，看到 `Ready at` 后再继续。如果手头已经有对应版本的压缩包，可给 `setup.py` 加上 `--assets-archive` 指定 GitHub 网页资源 `.tar.gz` 的路径，用 `--ruffle-archive` 指定 Ruffle 自托管版 `.zip` 的路径。

准备一台 Windows 电脑、一台 DS 系列掌机，以及一个已经获得 C-Gear（C 装置）的第五世代存档。让电脑和掌机连接到能互相访问的局域网。安装 Git、Python 3.11 或更高版本以及 uv。打开 PowerShell，依次运行以下命令。如果已经下载并解压本仓库，在含有 `setup.py` 的目录中打开 PowerShell，从第三条命令开始。[下载 Git](https://git-scm.com/downloads/win) · [下载 Python](https://www.python.org/downloads/windows/) · [安装 uv](https://docs.astral.sh/uv/getting-started/installation/)

```powershell
git clone https://github.com/goiku/dreamworld-cartridge.git
cd dreamworld-cartridge
python setup.py
cd runtime
uv sync --frozen
uv run --frozen python launch_windows.py --lan
```

如果电脑使用 Windows 的 Python 启动器，可以用 `py -3 setup.py` 运行安装程序。游玩期间保持窗口开启。窗口会显示供掌机使用的 `Game Sync address`，以及各语言的网页地址。英语端口为 8080，日语为 8081，简体中文为 8088。[打开本机中文版首页](http://127.0.0.1:8088/)

### 已经装过怎么更新

先等掌机同步结束，关闭开服和转接窗口。如果当初用 Git 下载了本仓库，在有 `setup.py` 的文件夹打开 PowerShell，运行下面两行，然后重新开服。这次更新复用已下载的网页素材，无需重新下载大型镜像。[查看源码更新工具](../tools/apply-source.py)

```powershell
git pull --ff-only
python tools/apply-source.py runtime
```

## 第一次把梦世界伙伴带回卡带

1. **让一只宝可梦入睡。** 在 C-Gear 下屏点 **Wi-Fi → 游戏同步**（日文「ゲームシンク」），让一只宝可梦入睡，等游戏提示同步完成。存档的游戏同步 ID 可以在游戏主菜单的「ゲームシンク設定」里查看。
2. **绑定存档。** 在电脑上打开本机网页，注册这个私服的账号并登录，再登记该存档的游戏同步 ID。如果网页提示需要激活，服主可以在 `runtime` 目录另开 PowerShell，运行下方的激活命令，把 `PlayerName` 换成玩家注册时填写的用户名。服主可以在本机激活账号，无需配置邮件服务。
3. **在网页结交伙伴。** 进入梦世界，跨过彩虹桥，通过小游戏与遇见的宝可梦交朋友。到梦之树献出一枚树果，选择想带走的伙伴。首次进入梦世界会收到同一种树果五枚。
4. **在网页准备唤醒。** 回到梦世界小屋，点右上角电源按钮，选「准备唤醒并结束」。核对要带走的伙伴，然后点「结束梦世界」。
5. **在卡带捕获。** 回到掌机，点 **Wi-Fi → 游戏同步**，唤醒先前入睡的宝可梦。同步结束后，打开 **WIRELESS → ハイリンク**，往北走进「ハイリンクの森」。和你选中的伙伴对话就能开始捕获。

```powershell
uv run --frozen python -m scripts.activate_account PlayerName
```

如果网页提示找不到 ID，先确认卡带在**当前这台私服**完成过一次同步，再核对游戏同步 ID。好友代码是联机时使用的另一组号码。同步中断时，保留同一台服务器和同一份存档，按照掌机提示操作，再进入游戏同步查看当前状态。

## 和不同网络的好友联机

双方各需要一台 Windows 电脑，分别与各自的掌机连接同一个局域网。两台电脑加入同一个 Tailscale 私有网络，掌机继续使用当地 Wi-Fi。转接程序已经通过模拟掌机通信测试，跨网的两台实体掌机完成对战或交换仍待验证。[Tailscale 设备互连说明](https://tailscale.com/docs/how-to/connect-to-devices)

下面的示例适合两个**彼此独立**的家庭网络。两边各自为电脑保留同一个可用的局域网地址，使用时请换成自己的地址。在两台电脑上分别运行 `tailscale ip -4` 查看各自的 Tailscale 地址，再用 `tailscale ping` 加对方地址确认互通。

| 地址 | 房主 | 好友 |
| --- | --- | --- |
| 电脑的 Tailscale 地址 | 100.64.10.1 | 100.64.10.2 |
| 电脑在本地局域网的地址 | 192.168.50.20 | 192.168.50.20 |
| 掌机在本地局域网的地址 | 192.168.50.31 | 192.168.50.32 |

等正在进行的同步结束后，用 Ctrl+C 停止局域网模式。房主在发布包目录打开 PowerShell，以本机模式启动服务。

```powershell
$env:DW_RELAY_STATE = Join-Path (Get-Location) "tools\DreamWorld-VPN-state.json"
cd runtime
uv run --frozen python launch_windows.py
```

分别在发布包目录打开三个 PowerShell 窗口。命令 **1** 由房主运行，用来启动转接中心。命令 **2** 也由房主运行，用来连接房主的掌机。命令 **3** 由好友在自己的电脑上运行，用来连接好友的掌机。好友电脑需要一份本仓库和 uv。三条命令中的 `--relay-ip` 要一致，两台电脑都要在各自连接掌机的网络上拥有这个地址，各自的掌机也都要能访问它。

```powershell
# 1
uv run tools/DreamWorld-VPN.py host --bind 100.64.10.1 --peer 100.64.10.1 --peer 100.64.10.2 --relay-ip 192.168.50.20
# 2
uv run tools/DreamWorld-VPN.py gateway --bind 192.168.50.20 --peer 192.168.50.31 --host 100.64.10.1 --tailscale-ip 100.64.10.1 --relay-ip 192.168.50.20 --no-web
# 3
uv run tools/DreamWorld-VPN.py gateway --bind 192.168.50.20 --peer 192.168.50.32 --host 100.64.10.1 --tailscale-ip 100.64.10.2 --relay-ip 192.168.50.20
```

两边的网关窗口都出现 `Battle hub confirmed the connection` 后，掌机联机时各自把主要 DNS 填成**当地电脑的局域网地址**。好友对战或直接交换需要双方在同一台游戏服务器上登记彼此的好友代码，再进入宝可梦中心的 Wi-Fi 俱乐部。普通 GTS 交换由一人预放，一人搜索并交换，预放者再次进入即可领取。要在本机自检转接程序，可在发布包目录运行 `uv run tools/DreamWorld-VPN.py self-test`。

如果用旧版私服寄放时出现 13265，请更新开服电脑上的私服，再进入 GTS。新版已补上宝可梦校验之后的名字检查。先查看有无已寄放的宝可梦，空着时再提交。

我用两个不同的网络做了实测：先在 melonDS 的《白》寄放一只 15 级冷水猴，再把 DS 实机连上另一个热点，用 10 级冷水猴换走了它。私服记录了一笔交换，随后也收到了寄放方领回宝可梦的确认。

### 去朋友的梦世界，把收获带回自己卡带

谁都可以当房主。两边先安装或更新到同一版，各自在**自己的私服**上激活账号、绑定卡带。每次配对关联一位房主、一个本地账号和一张卡。即使两人用户名相同，房主电脑也会单独建立访客身份。若房主已有这张卡的游戏同步记录，配对会停止。

1. **访客先在家让宝可梦入睡。** 掌机连接自己的私服，等游戏提示入睡同步完成。关掉自己服的梦世界网页，在本地开服窗口按 Ctrl+C 停服。让宝可梦一直睡到回家。
2. **房主发邀请。** 按上面的方法开服并启动私有中继，再双击 `runtime/Invite-Friend.cmd`。把房主电脑的 Tailscale IPv4 地址和**一次性邀请码**私下发给访客，邀请码 30 分钟内有效。房主等访客做完最后一次同步再关服。
3. **访客从自己的电脑加入。** 在自己电脑上运行上面的第 **3** 条网关命令，保留网页转发。双击 `runtime/Visit-Friend.cmd`，按提示输入房主的 Tailscale 地址、自己私服的用户名和密码，首次配对再输入邀请码。密码只在自己电脑上核对，浏览器会自动以访客身份打开。网页默认简体中文。要选日文或英文，可在 `runtime` 目录的 PowerShell 运行 `.\Visit-Friend.cmd --lang ja` 或 `.\Visit-Friend.cmd --lang en`。
4. **在朋友的网页上结束梦世界。** 许愿后，选好要送到卡带的道具，回到网页小屋，选「准备唤醒并结束」。关闭游戏标签页，接着在**访客的同步窗口**按 Ctrl+C。等它显示「最终同步已完成」。如果中途断网，恢复连接后保持房主服务和访客网关开启，在访客的 `runtime` 目录运行 `uv run --frozen python -m scripts.visit_friend --once` 补同步。
5. **回自己的私服唤醒。** 最终同步成功后，关掉访客网关，重新双击 `Start-DreamWorld-LAN.cmd`。确认掌机使用自己私服的 DNS，再用游戏同步唤醒宝可梦，到连入之森捕捉许愿选中的伙伴。网页宝箱里的库存和你选定送回卡带的道具分别记录。下次想请朋友来你家，双方互换角色，由新房主生成邀请码。

如果两边都产生了新进度，同步会暂停。关闭访客的游戏网页，两边暂停游玩。在访客电脑的 `runtime` 目录运行 `uv run --frozen python -m scripts.visit_friend --once --resolve host` 会保留**房主电脑上的进度**。要保留**访客自己电脑上的进度**，把最后的 `host` 换成 `home`。工具会先把两份进度备份到访客存档目录的 `visit-conflict-*.json`，然后应用你选的那一份。GTS 寄存和好友代码各自留在原来的游戏服务器上。

双服自检使用两台临时服务器和模拟卡带，覆盖双方互换主客、网页许愿、进度冲突及回自己服下载唤醒数据。在发布包目录运行 `runtime\.venv\Scripts\python.exe tools/check-visit.py runtime` 即可复查。上文的皮宝宝照片来自单机开服的实体卡带捕获。[查看双服测试源码](../tools/check-visit.py)
