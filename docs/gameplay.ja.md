# ドリームワールドの遊び方

[English](gameplay.en.md) · [日本語](gameplay.ja.md) · [简体中文](gameplay.zh.md)

練習したいときは「ミニゲーム体験」から好きなゲームを選べます。通常のプレイ中も、ゲーム画面上部の「ミニゲームの遊び方」から別のタブで確認できます。

[ドリームワールドの図解ガイド](http://127.0.0.1:8081/player-guide/pictures/)

## 寝かしつけからハイリンクの森まで

1. Cギアの下画面で「Wi-Fi → ゲームシンク」を選び、ポケモンを1匹寝かせる。通信が終わったら、ウェブで同じゲームソフトを選んでドリームワールドに入ろう。
2. 自分のホームから矢印に沿ってゆめのかけはしを渡り、ゆめしまへ。揺れる草むらやつららなどをクリックしてポケモンを探し、光る場所をクリックして道具を拾おう。
3. 出会ったポケモンとミニゲームで遊ぼう。ゆめの木に着いたら木の穴をクリックし、きのみを1個お供えして、連れて帰る仲間を選ぼう。
4. ホームの宝箱で持ち帰る道具を選ぼう。Cギアスキンを変えるなら、先にウェブの「カスタマイズ」で設定する。最後に画面右上の電源ボタンを押し、起こす準備をして終了しよう。
5. 同じソフトの「Wi-Fi → ゲームシンク」で寝ているポケモンを起こす。通信が終わったら「WIRELESS → ハイリンク」を選び、北のハイリンクの森で仲間に話しかけて捕まえよう。

## あんしんメールを送る

マイページのフレンドリストで交換相手やゆめともの「あんしんメールをおくる」を選ぶと、宛先を指定した画面が開きます。定型文を選んで送信し、「送信済み」で確認できます。相手が同じサーバーに該当するゲームのセーブデータでログインすると、受信箱で読めます。ポケモンを寝かせる必要はありません。

## ミニゲームの操作方法

### 迷子のポケモンを探そう

- 最初に迷子のポケモンの名前を覚えよう。矢印で場所を移動し、揺れる草むらや木、岩をクリックして調べよう。
- 「耳をすます」で鳴き声が大きければ、迷子は近くにいるよ。光る落とし物を拾って、その周りを探そう。

### アイスクリームを作ろう

- きのみを選び、アイスの容器でマウスを長押しして玉を大きくしよう。そのまま器の上まで運び、ボタンを離すと置けるよ。
- お手本の大きさに合わせて、3種類の味を組み合わせよう。器の真ん中から積むと安定するよ。

### 空を飛ぼう

- マウスで旗を動かすとポケモンが追いかけるよ。残り時間と距離を見ながらゴールを目指そう。
- 雲や苦手なタイプの印をよけて、同じタイプの印を3つ集めて加速しよう。スペースキーで一時停止できるよ。

### ホエルオーと遊ぼう

- マウスを左右に動かして、落ちてくるポケモンの下にホエルオーを移動しよう。クリックで潮を吹くよ。
- ポケモンを弾ませて、絵柄が合うボールを狙おう。次に落ちてくる仲間にも注目しよう。

### ポケモンカフェ・ドリンク運び

- お客さんの吹き出しで注文を確認しよう。クリックで飲み物を取り、ベルを動かしてタマゲタケを案内しよう。
- その飲み物を頼んだお客さんの前でクリックすると渡せるよ。トレイを傾けすぎないよう、ゆっくり動かそう。

### ビクティニの宝箱

- 光の玉を動かしてビクティニを案内しよう。岩をよけながらタイプのエネルギーを集め、マカロンでパワーアップしよう。
- 宝箱でレシラムかゼクロムと力を合わせよう。本編のキャンペーンをクリアしたら、カスタマイズでCギアスキンを確認できるよ。

### ろうそく消し

- 自分の番に、横一列につながっている炎を1つ以上選び、吹き消すボタンを押そう。消えたろうそくを飛び越えては選べないよ。
- 最後の炎を消したほうが負け。相手に最後の1本を残そう。

### 宝石あつめ

- トロッコが分かれ道に来たら、行きたい線路のマークをマウスのボタンを押したまま一筆でなぞり、ボタンを離そう。
- 線路の先を見て宝石が多い道へ。障害物にぶつかると、集めた宝石が落ちてしまうよ。

### ひやひやスイーツキャッチ

- 行きたい氷をクリックして滑ろう。お菓子の落ちる場所を見て、ほかのポケモンより先に取ろう。
- 氷にひびが広がったら場所を変えよう。水に落ちると戻るまでに時間がかかるよ。

### ボード遊び

- ボードと乗るポケモンを選ぼう。パワーゲージが高いところでクリックし、次のクリックで角度を決めよう。
- タイミングよくジャンプし、空中ではマウスでボードの傾きを調整しよう。風やトランポリンを利用して1500メートルを目指そう。

### ポケモンビストロ・ドリンク運び

- 吹き出しを見て注文を確認し、カウンターをクリックして飲み物を取ろう。ベルでタマゲタケをお客さんの前まで案内しよう。
- ゆっくり動かしてからクリックで手渡そう。制限時間内に正しい飲み物をたくさん届けよう。

### リザードンの宝箱

- 光の玉を動かすとリザードンがついてくるよ。岩をよけながらタイプのエネルギーを集めよう。
- パワーアップ中は岩を壊せるよ。宝箱まで来たら、集めたエネルギーで大技を出そう。
