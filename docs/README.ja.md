# ポケモンドリームワールド　ゆめの木からDSのハイリンクの森へ

[English](../README.md) · 日本語 · [简体中文](README.zh-CN.md)

第五世代のポケモンドリームワールドを有志が復元したものです。パソコンでゆめしまを訪れ、仲良くなったポケモンをゆめの木で選ぶと、自分のゲームカードの「ハイリンクの森」で捕まえられます。このリポジトリには、個人用サーバーを構築するためのソースコードの変更とセットアップ用ツールを収録しています。

## DSを使わずに全12種類のミニゲームを遊ぶ

トップページまたはドリームワールドの画面上部で **ミニゲーム体験** を選びます。一覧から遊びたいゲームを開き、終了後はもう一度遊ぶか一覧に戻れます。ログイン、ポケモンの寝かしつけ、DSとの通信は不要です。体験用のポケモンときのみが用意されており、得点や道具は通常のセーブと独立しています。メニューは言語を切り替えられますが、一部のゲーム画像内の文字は元の言語のままです。[サーバーPCで体験ページを開く](http://127.0.0.1:8081/practice/)

スマートフォンをサーバーPCと同じネットワークに接続し、ウェブサイトのスマートフォン用案内に表示されるアドレスからトップページを開いてください。ポケモンや道具をDSに連れて帰る場合は通常の島で遊びます。

## ペアリングした友だちと遊ぶ

ゆめとも一覧から友だちのプロフィールを開くと、乾いた畑への水やりや、おすそわけ棚の道具交換を申し込めます。両方のサーバーを更新し、一度同期してください。その後は相手がオフラインでも申し込めます。交換に出す道具は一度確保され、次回の接続で交換が成立します。すでに相手の道具が入れ替わっていた場合は返却されます。結果はプロフィールで確認できます。

自分のアカウントで友だちのサーバーに遊びに行くと、配信の受取記録と予約も引き継がれます。カートリッジで受け取る前に自分のサーバーへ同期してください。カートリッジのカードアルバムは自分のサーバーで読み込みます。

## 日本版PWTのダウンロードトーナメント

配信ページの日本版カタログから **Pokémon World Tournament** を開きます。9大会・10ファイルがあり、ジュニア部門には初期版と修正版があります。大会ファイルを直接保存するか、日本版**ブラック2・ホワイト2**の512 KiBのセーブバックアップを選ぶと、ブラウザー内で登録済みの大会と空き枠を確認できます。**コピーに追加**を押すと空き枠を使って新しいコピーを保存します。続けて選んだ大会もそのコピーに入ります。元のバックアップは保管してください。コピーの生成はテスト用のセーブで確認済みです。PWT会場のダウンロードでは9大会を配信し、ジュニア部門には修正版を使用します。配信リストとファイルのチェックサムはテスト済みです。『ブラック2・ホワイト2』の実機での受信は未確認です。[サーバーPCで大会を開く](http://127.0.0.1:8081/campaign/japan/tournaments/) · [大会アーカイブ](https://projectpokemon.org/home/files/category/51-pok%C3%A9mon-world-tournaments/)

## 自分のDSで遊ぶ

**DSとドリームワールドを起動するPCを、自宅の同じネットワークにつなぎます。** 機器同士が通信できれば、同じWi-Fiでもテザリングでも遊べます。ひとりで遊ぶ場合、Tailscaleの設定や招待は不要です。

1. **PCでサーバーを起動します。** 初回は下の[Windowsでのセットアップ手順](#windowsでサーバーを起動する)に従います。次回からは `runtime` フォルダーの `Start-DreamWorld-LAN.cmd` をダブルクリックし、プレイ中はウィンドウを開いたままにします。
2. **ウェブサイトでDNSを確認します。** そのPCでドリームワールドのトップページ、またはゲーム画面の上にある **「DSに設定するDNSを調べる」** をクリックします。アドレスが表示されないときは、LANモードで起動していることとWi-Fiの接続を確認し、「もう一度確認」をクリックしてください。[このPCのDNSガイドを開く](http://127.0.0.1:8081/player-guide/#dns)
3. **表示されたアドレスをDSに入力します。** ガイドの **「本体でのDNS設定」** で機種を選びます。ゲームで使う接続先の設定を開き、DNSの自動取得を「しない」にして、表示された数字を「プライマリDNS」に入力します。保存して接続テストを行います。アドレスが変わらなければ、次回もその設定で遊べます。

**スマートフォンやタブレットで遊ぶには、**PCでLANモードを起動し、端末をPCと同じWi-Fiに接続します。PCのトップページ、またはゲーム画面上部の **「スマホ用のURL」** をクリックします。表示されたアドレスをポート番号までスマートフォンのブラウザーに入力し、ゲームカードを登録したアカウントでログインしてください。寝かしつけの通信が完了したら、ポケモンを起こすまでDSはオフラインのままで遊べます。LANモードの自動設定でPCのWi-Fiを切り替えたときは、新しい接続が確立したらこのページを再読み込みしてURLを確認してください。携帯端末向けの表示はモバイルブラウザーのエミュレーションで確認しています。[このPCでスマホ用のURLを調べる](http://127.0.0.1:8081/player-guide/phone/)

### サーバーと同じPCでmelonDS 1.1を使う

1. サーバーを起動し、同じPCでDNSの案内を開いて、機種を「melonDS」に切り替えます。[エミュレーターのDNSを確認](http://127.0.0.1:8081/player-guide/#melonDS)
2. melonDSを間接接続モードにします。ゲームの「Wi-Fiコネクション設定」で「melonAP」の接続先を開き、「DNS自動取得」を「しない」にして、案内に出た数字をプライマリDNSに入力します。保存して接続テストを行います。サーバーがPC内のみで動作している場合は `10.64.0.1` です。[melonDS 1.1のネットワーク設定](https://github.com/melonDS-emu/melonDS/blob/1.1/src/net/Net_Slirp.cpp#L39-L42)
3. ゲーム内のレポートから再開し、下画面の **Cギア → Wi-Fi → ゲームシンク** で1匹寝かせます。サイトがIDを認識していてもソフトの種類が未登録の場合は、寝かしつけを完了してから登録し直してください。接続テスト成功後も翻訳版で暗転する場合は、ゲーム内のセーブ（`.sav`）をコピーし、同じ日本版ソフトの未改変の手持ちROMで動作を比べてください。

### 寝かしつけ制限を解除

**純正カートリッジで DNS だけを変更する場合。** サーバーは起こした直後の寝かしつけを受け付けます。4作品のテスト用セーブで、起床を挟んで2回の送信に成功しました。カートリッジは寝かせられるポケモンの一覧を要求する前に、セーブ内の日付と DS の時計を比較します。通常の起床応答にこの日付を消去する設定はありません。同じポケモンを寝かせたままなら、起こす準備をするまでウェブから夢の世界に戻れます。

ゲームでレポートを書いて melonDS を閉じます。サイトの **寝かしつけ制限を解除** で本体の日付を確認し、セーブフォルダーと対象のファイルを選んで **バックアップしてセーブを更新** を押します。512 KiB の .sav を個別に選んでコピーを保存することもできます。実機では元のセーブを書き出し、処理後のコピーを書き戻してください。ファイルはこの端末内で処理します。実機の時計はアップロード前にチェックされ、Wi-Fi だけでは書き換えられません。[ウェブ版を開く](http://127.0.0.1:8081/player-guide/#tuck-in)

DS の電源が切れていても設定する DNS を確認できます。マイページでプレイ可能と表示されたら、そのリンクから開始できます。自宅の看板には選択中のソフトのトレーナー名が表示されます。

ゲーム内でレポートを書き、melonDS を終了します。Windows のインストール先 `runtime` で **Start-melonDS.cmd** を開き、melonDS 1.1、普段遊ぶソフト、同じ地域・バージョンの未改変ソフト、最新の `.sav` を順番に選びます。ツールはプレイヤーごとにセーブデータのコピーを作ります。次回からは新しいフォルダーにある **DreamWorld.cmd** を開いてください。

| 「解除睡眠限制」のボタン | 操作 |
| --- | --- |
| 平时游玩（汉化版） | 普段のソフトで遊びます。切り替える前にレポートを書いて melonDS を終了します。 |
| 申请入睡（原版） | 本体や時計の変更による待ち時間と、同じ日の寝かしつけ制限を解除して原版を起動します。下画面で **Wi-Fi → ゲームシンク → はい** と進みます。 |
| 唤醒并领取（原版） | ウェブで起こす準備をした後、原版を起動してゲームシンクで受け取ります。 |

どのボタンでも同じセーブデータを使います。待ち時間を変更する前にバックアップを保存します。同じタイマーを使うほかのイベントにも反映されます。ツールは melonDS の日付を読み、前回の日付が今回の寝かしつけを妨げる場合のみ、起きているセーブ枠の記録日を調整します。両方の待ち時間について、ブラック・ホワイトと各続編でセーブデータのテストを実施しました。すでに設定している場合は、新版の Start-melonDS.cmd で「更新『解除睡眠限制』」を選び、以前のフォルダーを指定してください。同じ日の2回目の寝かしつけはゲーム内での検証が必要です。実機ではアップロード前にソフトが待ち時間を確認します。自分のカートリッジからセーブを取り出して復元できる場合は、本体に表示される日付を入力し、ツールで 512 KiB のコピーを作って書き戻し、同じ本体・時計設定で続けてください。[サーバーPCでガイドを開く](http://127.0.0.1:8081/player-guide/#tuck-in) · [セーブデータの項目](https://github.com/kwsch/PKHeX/blob/6c9583883c7551ac74a4b74180cead249d4277b8/PKHeX.Core/Saves/Substructures/Gen5/AdventureInfo5.cs#L36) · [任天堂のゲームシンクFAQ](https://www.nintendo.co.jp/ds/irbj/qa/index.html) · [ゲームシンクの日付判定](https://github.com/fuddlesworth/pokebw2/blob/3afa377e9056f6ba75e572f9296b1637fc694a44/src/ov199/gsync_state.c#L1446-L1473)

### 簡体字中国語版『ホワイト』2.1 のゲームシンクを修復する

Python 3.11 以降で[修復ツール](../tools/repair-white-sync.py)を開きます。未改変の日本版『ホワイト』、簡体字中国語版 2.1、新しい出力ファイル名の順に選ぶと、手元の PC で修復版が作られます。設定済みなら **解除睡眠限制 → 改用《白》汉化同步修复版** で修復版を指定します。新規設定では普段用と通信用の両方に修復版を指定してください。同じセーブデータでプレイ、寝かしつけ、受け取りを続けられます。

中国語版では、ゲームシンクが28件の画像を読む `a/1/4/3` に、別画面の47件が入っていました。ツールは日本版の通信プログラムと画像構成を復元し、翻訳済みの画像を本来の `a/0/4/3` に戻します。中国語のフォント、メッセージ、Wi-Fi 設定の翻訳を引き継ぎ、Cギアの「ゲームシンク」ボタンも中国語にしています。melonDS 1.1 のコアで同じセーブと入力を使い、日本版と修復版は接続の確認画面に進み、修復前は暗転することを確認しました。この検証は接続確認までです。


## イベント配信を受け取る

配信ページの **「実機の受信順」** を開くと、選択中のソフトが次の接続で受け取るカードが先頭に表示されます。ゲームシンクの欄では今回の起床で送る仲間や道具と次回以降に回るものを確認できます。開いている間は15秒ごとに更新します。[実機の受信順を開く](http://127.0.0.1:8081/campaign/queue/)

**イベント配信 → ふしぎなおくりもの** の **未受取のカードをすべて予約** を押すと、全ページの未受取カードのうち、種類を選ぶ必要のないものが待機列の末尾に加わります。ボタンには追加できる枚数が表示されます。どれか1種類だけ受け取れるプレゼントは、一覧から欲しいものを個別に予約してください。DSで順番に受け取れます。

ドリームワールドの **イベント配信** を開き、受け取るソフトを選びます。更新後は、このソフトで一度ゲームシンクを行ってください。ソフトのバージョンと言語に対応した配信が表示されます。[サーバーのPCで日本語の配信ページを開く](http://127.0.0.1:8081/campaign/)

- **ドリームワールドのキャンペーン**。仲間の横にある **自分のセーブデータに配信** を押します。ドリームワールドを終了し、起こす準備をしてからゲームシンクでポケモンを起こしてください。ハイリンクの森で仲間を捕まえられます。ゲームから受信確認が届くと配信済みになります。履歴にはこのサーバーでの配信を記録します。
- **ふしぎなおくりもの**。配信ボタンを押してから、タイトル画面で **ふしぎなおくりもの → おくりものを うけとる → Wi-Fi** と進みます。受信後はポケモンセンターの配達員から受け取り、レポートを書いてください。複数のカードが待機中なら **次にこのカードを受け取る** で1枚ずつ選べます。
- **受取履歴の確認**。次のゲームシンクでカードアルバムを読み取ると、カードの受信と配達員からの受け取りを区別して表示します。**バックアップを確認** では登録したソフトの最新の512 KiBの生の `.sav` を読み取れます。同じ番号の別カードがある場合、特定できた範囲を表示します。

カードは固定版のイベントアーカイブから、選択時に1枚ずつ取得します。通信は一時セーブデータでテストしています。私（goiku）は自分の日本版『ブラック』のゲームカードで、Cギアスキン、ドリームワールドのイベント配信、ふしぎなおくりものの3種類を受け取りました。下のピィの写真はゆめのき経由で捕獲したときのものです。[第5世代イベントアーカイブ](https://github.com/projectpokemon/EventsGallery/tree/f1f3095183ee54dca63216164adb1f278714ec55/Released/Gen%205) · [ドリームワールドの出会いデータ](https://github.com/kwsch/PKHeX/blob/master/PKHeX.Core/Legality/Encounters/Data/Gen5/Encounters5Dream.cs)

ウェブで起こす準備を済ませた後も、DSがダウンロードを始めるまでは配信の仲間を追加したり、Cギアスキンを保存したりできます。開始後に選んだ仲間や今回の空き枠に入らなかった仲間は、次に起こすときに受け取れます。ふしぎなおくりものはゲームのタイトル画面から受け取れます。[サーバーを起動したPCで手順を見る](http://127.0.0.1:8081/player-guide/#distributions)

**LANのみで配信する準備**。サーバーのPCで、インストールした DreamWorld フォルダーから `.venv\Scripts\python.exe scripts\prepare_japanese_gifts.py` を1回実行します。約142 KiBをダウンロードし、各カードを照合します。その後はインターネット回線を切っても、同じLAN内で受け取れます。一覧の閲覧にダウンロードは不要です。事前に用意しない場合は、選んだカードをその都度ダウンロードします。複数のカードが同じ番号を持ち、セーブデータから種類を特定できない場合は「要確認」と表示します。特定できたカードの履歴は、アルバムから捨てた後も残ります。

## 友だちがオフラインでも島を訪れる

各プレイヤーは自分のサーバーで、ゲームカードを登録した自分のアカウントにログインします。夢の世界の「友だちを見る」を開き、次のどちらかの方法で島を保存します。

- **一度ペアリングして自動更新。** 両方のPCで同じバージョンのサーバーを起動し、同じLANまたはTailscaleプライベートネットワークに接続します。一人が友だち一覧で有効時間30分の招待コードを発行し、相手に個別に送ります。同じWi-FiならLANアドレス、離れた場所からならTailscaleアドレスのコードを選びます。相手が自分のページにコードを貼り付けてペアリングすると、接続中は約30秒ごとに島の更新を確認し、保留中の足あとも届けます。DSや対戦用の中継プログラムを起動する必要はありません。Windowsのファイアウォールで遮断された場合は、家庭内LANまたは友だちのTailscaleアドレスからTCP 8094への接続を許可してください。
- **ファイルで共有。** 島主が「自分の島を書き出す」でファイルを送り、訪問者が自分のページの「友だちの島を読み込む」から開けば、すぐに訪問できます。更新や足あとの自動配信には、一度ペアリングしてください。古いファイルを読み込んでも、新しい島は残ります。

**家から遊びに行く。** ゲーム内のゆめともマップで相手を選ぶか、ウェブの「友だちを見る」で「友だちのホームへ」を選ぶと、元のドリームワールドにある相手のホームへ行けます。「部屋に入る」を選ぶと、相手が家具を置いた部屋が開きます。表示される最終更新日時で島の情報の新しさがわかります。ペアリング後は、両方のサーバーがオンラインの間に同じ島が更新されます。友だちがPCとDSの電源を切った後も、同じ入口から訪問できます。ペアリング後は部屋の上にあるゲーム記録とお手伝いのリンクから、乾いた畑に水をやったり、棚の道具の交換を申し込んだり、結果を確認したりできます。「島に戻る」を押すと同じ部屋に戻れます。足あとは訪問者のPCに保存され、再接続時に一度だけ島主の記録に加わります。[当時の公式ヘルプの保存版](https://github.com/minibug1021/dreamworld-assets/blob/6e0550dab8552cd54bd976d4023f9ec0c43f6d7c/ja.pokemon-gl.com/support/help/world/820/index.html#L180)

**新しい仲間と出会う。** まず自分のサーバーでポケモンを寝かせます。友だちの家で訪問者用の探検を始め、見本と同じ足あとを三つの道から選びます。仲良くなったら自分のきのみを一個供えてゆめの木で願い、起こす準備をして終了します。自分のサーバーでポケモンを起こしてハイリンクの森に向かいます。探検と受け取りは訪問者自身のセーブに記録され、島主のポケモンや道具はそのままです。

ゲームシンクで取得したソフトの種類、トレーナー名、バッジ数、プレイ時間、寝かせたポケモン、ゆめポイント、道具、家具、メダル、仲良くなったポケモンなどが表示されます。ゲームカードのセーブ全体、ボックスや手持ちの一覧、ゲームシンクID、パスワード、ログイン情報は含まれません。ファイルを受け取った人は、この表示用データを読むことができます。

## Windowsでサーバーを起動する

ディスクに **6 GB 以上の空き容量**を用意してください。元のウェブサイトのミラーだけで展開後約 3.8 GiB あります。初回は、この版が使う上流のソースと素材をダウンロードしてゲーム用のファイルを準備します。ミラーのダウンロードと展開には時間がかかるため、`Ready at` の表示を待ってから次に進みます。該当バージョンのアーカイブを持っている場合は、`setup.py` の `--assets-archive` に GitHub のウェブ素材の `.tar.gz`、`--ruffle-archive` に Ruffle のセルフホスト版 `.zip` のパスを指定できます。

Windows PC、DS シリーズの本体、Cギアを入手済みの第五世代のセーブデータを用意します。PC と DS は互いに通信できる同じローカルネットワークに接続してください。Git、Python 3.11 以降、uv をインストールします。PowerShell を開き、以下のコマンドを順に実行してください。すでにリポジトリをダウンロードして展開した場合は、`setup.py` があるフォルダーで PowerShell を開き、3 行目から実行します。[Git のダウンロード](https://git-scm.com/downloads/win) · [Python のダウンロード](https://www.python.org/downloads/windows/) · [uv のインストール](https://docs.astral.sh/uv/getting-started/installation/)

```powershell
git clone https://github.com/goiku/dreamworld-cartridge.git
cd dreamworld-cartridge
python setup.py
cd runtime
uv sync --frozen
uv run --frozen python launch_windows.py --lan
```

Windows の Python ランチャーを使う場合は、`python setup.py` の代わりに `py -3 setup.py` を実行します。プレイ中はサーバーのウィンドウを開いたままにします。DS に設定する `Game Sync address` と、各言語のウェブサイトのアドレスが表示されます。英語版はポート 8080、日本語版は 8081、簡体字中国語版は 8088 です。[このPCの日本語版ホームページ](http://127.0.0.1:8081/)

ゲームシンクの完了を待ち、サーバーと中継のウィンドウを閉じます。Gitで取得した配布フォルダー（`setup.py` がある場所）でPowerShellを開き、次の2行を実行してからサーバーを再起動します。ダウンロード済みの大きなウェブ素材を再利用できます。[ソース更新ツール](../tools/apply-source.py)


## 新しい仲間をゲームカードに連れて帰る

1. **ポケモンを寝かせます。** Cギア下画面の **「Wi-Fi」→「ゲームシンク」** を選び、ポケモンを 1 匹寝かせて、通信完了の表示を待ちます。ゲームシンクIDコードはゲームのメインメニューの「ゲームシンク設定」で確認できます。
2. **セーブデータを登録する。** PC でローカルのホームページを開き、このサーバー用のアカウントを作成します。ログインして、先ほどのゲームシンクIDコードを登録します。有効化を求められた場合は、サーバー管理者が `runtime` フォルダーでもう一つ PowerShell を開き、下に示す有効化コマンドの `PlayerName` を登録したユーザー名に置き換えて実行します。管理者はメールの設定を省略し、PC 上でアカウントを有効にできます。
3. **ウェブで仲良くなる。** ドリームワールドに入り、虹の橋を渡ります。出会ったポケモンのミニゲームをクリアし、ゆめの木できのみを 1 個お供えして、連れて帰りたい仲間を選びます。初回には同じ種類のきのみを 5 個もらえます。
4. **起こす準備をする。** ウェブで自分のホームに戻り、右上の電源ボタンを押します。ポケモンを起こす準備をして終了する方を選び、連れて帰る仲間を確認して終了します。
5. **ゲームで捕まえる。** DS で再び **「Wi-Fi」→「ゲームシンク」** を選び、寝かせたポケモンを起こします。通信完了後、Cギアの **「WIRELESS」→「ハイリンク」** でハイリンクへ移動します。北へ進み、「ハイリンクの森」で仲間に話しかけると捕獲できます。

```powershell
uv run --frozen python -m scripts.activate_account PlayerName
```

ウェブサイトで ID が見つからない場合は、**今使っているサーバー**にそのゲームカードから初回の同期が完了しているか、ゲームシンクIDコードを正しく入力したかを確認します。ともだちコードは対戦・交換に使う別の番号です。通信が途切れた場合は、同じサーバーとセーブデータのまま本体の表示に従い、再びゲームシンクで状態を確認してください。

## 別のネットワークにいる友だちと遊ぶ

それぞれのプレイヤーが、手元の DS と同じローカルネットワークに接続した Windows PC を 1 台ずつ用意します。2 台の PC は同じ Tailscale プライベートネットワークに参加し、DS はそれぞれの Wi-Fi に接続したままにします。中継プログラムは模擬端末による通信でテスト済みです。異なるネットワーク上の実機 2 台で対戦・交換を最後まで行う試験は未実施です。[Tailscale の接続ガイド](https://tailscale.com/docs/how-to/connect-to-devices)

以下は、**互いに独立した**二つの家庭内ネットワークで、それぞれの PC に同じ空き LAN アドレスを予約する例です。例のアドレスを実際の値に置き換えます。各 PC の Tailscale アドレスは `tailscale ip -4` で確認でき、`tailscale ping` の後に相手のアドレスを指定すれば疎通を確認できます。

| アドレス | ホスト | 友だち |
| --- | --- | --- |
| PC の Tailscale アドレス | 100.64.10.1 | 100.64.10.2 |
| PC の自宅 LAN アドレス | 192.168.50.20 | 192.168.50.20 |
| DS の自宅 LAN アドレス | 192.168.50.31 | 192.168.50.32 |

進行中のゲームシンクが完了したら、Ctrl+C で LAN モードを停止します。ホストの PC で配布フォルダーから PowerShell を開き、サーバーをローカルモードで起動します。

```powershell
$env:DW_RELAY_STATE = Join-Path (Get-Location) "tools\DreamWorld-VPN-state.json"
cd runtime
uv run --frozen python launch_windows.py
```

配布フォルダーで PowerShell を個別に開きます。コマンド **1** はホスト PC で中継の中心を起動し、**2** は同じ PC の別ウィンドウで手元の DS を接続します。**3** は友だちの PC で実行します。友だちの PC にもこのリポジトリのコピーと uv が必要です。`--relay-ip` には 3 回とも同じ値を使います。このアドレスは両方の PC でそれぞれ DS 側のネットワークに割り当てられ、その DS から到達できる必要があります。

```powershell
# 1
uv run tools/DreamWorld-VPN.py host --bind 100.64.10.1 --peer 100.64.10.1 --peer 100.64.10.2 --relay-ip 192.168.50.20
# 2
uv run tools/DreamWorld-VPN.py gateway --bind 192.168.50.20 --peer 192.168.50.31 --host 100.64.10.1 --tailscale-ip 100.64.10.1 --relay-ip 192.168.50.20 --no-web
# 3
uv run tools/DreamWorld-VPN.py gateway --bind 192.168.50.20 --peer 192.168.50.32 --host 100.64.10.1 --tailscale-ip 100.64.10.2 --relay-ip 192.168.50.20
```

両側のゲートウェイに `Battle hub confirmed the connection` と表示されたら、対戦・交換に使う DS のプライマリ DNS を**同じ家にある PC の LAN アドレス**に設定します。フレンド対戦・交換では、同じゲームサーバーでお互いのともだちコードを登録し、ポケモンセンターの Wi-Fi クラブに入ります。通常の GTS 交換では、一人がポケモンを預け、もう一人が検索して交換したら、預けた側が GTS に入り直して受け取ります。中継の単体テストは配布フォルダーから `uv run tools/DreamWorld-VPN.py self-test` で実行できます。

旧版のサーバーで GTS に預けようとしてエラー 13265 が出た場合は、サーバーを更新して GTS に入り直してください。ポケモンの確認後に行う名前チェックに対応しました。もう一度預ける前に、預かり状況を確認できます。

私自身が異なる二つの回線で確認しました。melonDS の『ホワイト』でレベル15のヒヤップを預け、別の回線のテザリングに接続した DS 実機からレベル10のヒヤップと交換しました。交換履歴は1件で、その後、預けた側のゲームから受け取り完了の通知も届きました。

### 友だちのワールドを訪ね、仲間や道具を自分のゲームカードに連れて帰る

どちらのPCでもホストになれます。両方を同じ版に更新し、それぞれ**自分のサーバー**でアカウントを有効化してゲームカードを登録します。ペアリングはホスト1台・自宅アカウント1つ・ゲームカード1枚の組み合わせです。ユーザー名が同じでも、ホスト側には独立した訪問者用アカウントが作られます。ホストに同じゲームシンクIDの記録がある場合、ペアリングは停止します。

1. **訪問する人は、自宅でポケモンを寝かせます。** 自分のサーバーでゲームシンクが完了したら、自宅のウェブページを閉じ、サーバーのウィンドウでCtrl+Cを押して停止します。ポケモンは帰宅するまで寝かせておきます。
2. **ホストは招待コードを送ります。** 上記の手順でサーバーと中継を起動してから、`runtime/Invite-Friend.cmd` をダブルクリックします。自分のPCのTailscale IPv4アドレスと、30分間有効な使い切りのコードを訪問する友だちだけに伝えます。最後の同期が終わるまでサーバーと中継を起動しておいてください。
3. **訪問する人は、自分のPCから参加します。** 上記のコマンド **3** でウェブ転送を有効にしたゲートウェイを起動します。`runtime/Visit-Friend.cmd` をダブルクリックし、ホストのTailscaleアドレスと、自宅のユーザー名・パスワードを入力します。初回は招待コードも入力してください。パスワードは自分のPCで照合され、ブラウザーが訪問者として自動的に開きます。既定の表示言語は簡体字中国語です。日本語で遊ぶには `runtime` でPowerShellを開いて `.\Visit-Friend.cmd --lang ja` を実行します。英語にするには `--lang en` を指定します。
4. **友だちのウェブサイトで終了します。** ゆめの木で願いごとをし、ゲームカードに送る道具を選んだら、自分のホームに戻ってポケモンを起こす準備をして終了します。ゲームのタブを閉じて**訪問者の同期ウィンドウ**でCtrl+Cを押し、`Final sync complete` が表示されるまで待ちます。途中で回線が切れた場合は再接続し、ホストとゲートウェイを起動したまま、訪問者の `runtime` で `uv run --frozen python -m scripts.visit_friend --once` を実行してください。
5. **自宅のゲームシンクで起こします。** 最終同期の完了後に訪問者のゲートウェイを止め、`Start-DreamWorld-LAN.cmd` を起動します。DSのDNSが自宅のサーバーを指していることを確認し、ポケモンを起こしてください。願いごとで選んだ仲間はハイリンクの森で捕まえられます。宝箱の中身と、ゲームカードに送るために選んだ道具は別々に記録されます。次に相手の家から遊びに来てもらうときは、役割を入れ替えて新しいホストが招待コードを発行します。

両方のサーバーで進行状況が変わった場合は、同期が一時停止します。訪問中のブラウザーを閉じ、両方のPCでプレイを中断してください。訪問者の `runtime` で `uv run --frozen python -m scripts.visit_friend --once --resolve host` を実行すると**訪問先の記録**を採用します。**自宅の記録**を採用するには末尾を `--resolve home` に変更します。どちらを選んでも、適用前に両方の記録が訪問者のセーブフォルダーの `visit-conflict-*.json` に保存されます。GTSに預けたポケモンとともだちコードは、登録したゲームサーバーに残ります。

双方向の訪問、ウェブ上の願いごと、同期競合の解決、自宅に戻ってからの起床データの受け取りは、一時サーバー2台と模擬ゲームカードを使って検証します。配布フォルダーで `runtime\.venv\Scripts\python.exe tools/check-visit.py runtime` を実行すると再確認できます。上の実機写真は、自宅サーバーでの単独プレイでピィを捕まえた際のものです。[双方向の訪問テスト](../tools/check-visit.py)
