# 梦世界游戏教程

[English](gameplay.en.md) · [日本語](gameplay.ja.md) · [简体中文](gameplay.zh.md)

只想练手时，打开私服网页里的「小游戏试玩」。正式游玩时，可以从画面上方打开「小游戏玩法」，原来的一局会保留在原标签页。

[梦世界图解教程](http://127.0.0.1:8088/player-guide/pictures/)

## 第一次从入睡玩到捕获

1. 在掌机 C 装置下屏点“Wi-Fi → 游戏同步”（日文「ゲームシンク」），选一只宝可梦入睡。等同步完成后，在网页选择绑定这张卡带的存档，再进入梦世界。
2. 从小屋沿箭头走到彩虹桥，过桥进入梦之岛。点击晃动的草丛、冰锥等物体寻找宝可梦；看到闪光就点击拾取道具。
3. 点击遇见的宝可梦，玩它的小游戏。到了梦之树，点击树洞，献上一枚树果，再从结交的伙伴里选一只带回去。
4. 回到小屋，在宝箱里选好要送回的道具。想换 C 装置壁纸时，先在网页“自定义”里选好。最后点梦世界右上角的电源按钮，选择“准备唤醒并结束”，核对伙伴后确认。
5. 回到同一份游戏存档，用“Wi-Fi → 游戏同步”唤醒入睡的宝可梦。同步结束后打开“WIRELESS → ハイリンク”，往北进连入之森，与刚才许愿的伙伴对话并捕捉。

## 游戏内操作

### 寻找宝可梦

- 看清开场给出的宝可梦名字。点击路口的箭头换场景，点击正在摇晃的草丛、树木或石头，查看藏在里面的宝可梦。
- 点击“仔细听”。叫声越清楚，目标就越近。发现闪光先点击拾取失物，再搜索附近摇晃的地方。

### 堆冰淇淋

- 选择树果后，在左边的冰淇淋盒里按住鼠标，让冰淇淋球慢慢变大。保持按住，把球拖到碗上方，松手放下。
- 对照画面上的参考大小，轮换三种口味，从碗中央开始堆。时间结束时会结算高度、大小和口味搭配。

### 天空竞速

- 移动鼠标控制手旗，宝可梦会朝手旗飞。用剩余时间和距离判断路线，在倒计时结束前飞到终点。
- 避开云朵和弱点属性标记。收集与伙伴相同的属性标记，集齐三个可以加速。按空格键暂停。

### 吼鲸王喷水

- 左右移动鼠标控制吼鲸王的位置。让下落的宝可梦对准喷水孔，点击鼠标喷出水柱，把它弹回空中。
- 瞄准和宝可梦图案相配的彩球。留意下一只落下的伙伴，连续击破彩球能得到连击奖励。

### 宝可梦咖啡馆·送饮料

- 看客人头上的气泡，记下饮料的颜色。点击取饮料，让哎呀球菇端着托盘跟随铃铛移动。
- 在点了这杯饮料的宝可梦面前点击送出。可以同时拿几杯，但移动太快会倾斜或洒出饮料。

### 比克提尼的宝箱

- 移动光球引导比克提尼飞行，绕开岩石，沿路收集属性能量。吃到马卡龙能暂时强化。
- 积攒能量，在宝箱前与莱希拉姆或捷克罗姆合力发动特别攻击。正式活动的 C 装置壁纸可到主页“自定义”查看。

### 吹灭蜡烛

- 轮到你时，点击一排横向相连的烛火，再点“吹灭”。一次可以选一根或多根，中间不能越过已经熄灭的蜡烛。
- 吹灭最后一簇火的一方会输。设法把最后一根留给对手，时间用完前还可以继续挑战。

### 收集宝石

- 勾魂眼坐矿车来到岔路时，按住鼠标，照着想走的那条轨道上的图案一笔画完，再松开。
- 先看两条路上有什么，选宝石多的那条。碰到高山植物会震落已经收集的宝石。

### 冰上甜点争夺战

- 点击想去的冰格，宝可梦就会向那里滑行。观察甜点落点，抢在其他宝可梦前面捡起来。
- 冰面经过或停留后会开裂。及时离开裂纹多的格子，掉进水里要等一会儿才能回到场上。

### 滑板飞越湖面

- 选好滑板和搭乘的宝可梦。看准能量槽接近满格时点击，再点击确定起跳角度。
- 在合适的时机点击跳起，飞行中移动鼠标调整滑板角度。跟随风向箭头、踩中蹦床，争取飞过 1500 米。

### 宝可梦餐厅·送饮料

- 先看客人想喝哪种饮料。点击柜台取杯，用铃铛引导哎呀球菇，把托盘送到点单的宝可梦面前。
- 缓慢移动保持平衡，到客人面前点击交杯。留意杯子的颜色，尽量在时间结束前完成订单。

### 喷火龙的宝箱

- 移动光球，喷火龙会跟着它飞行。收集沿途的属性能量，注意绕开岩石。
- 拿到强化道具后可以撞碎岩石。抵达宝箱时用积蓄的能量发动特别攻击。
